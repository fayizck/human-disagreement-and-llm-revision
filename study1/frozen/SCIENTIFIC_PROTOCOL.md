# Frozen N=300 scientific protocol

The study is one prospectively frozen N=300 experiment. The 200+100 division is operational only. Every item-model pair has 50 independent baselines, one independent initial, and four conditional branch slots. A valid actual initial activates two alternatives × neutral/directed branches, each independently serialized from the original prompt and actual initial response. Invalid initials seal all four branches ineligible. Neutral and directed text is inherited byte-for-byte through the frozen prompt manifest. The n=40 checkpoint is a nested sensitivity computed from zero-based baseline indices 0–39; the corrected pilot diagnostic affected only pilot reporting and does not select items, labels, prompts, IDs, or the n=50 main measurement.
